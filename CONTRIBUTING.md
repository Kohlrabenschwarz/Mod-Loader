# Contributing

Use English for issues, pull requests, commit messages, and project documentation. Localized UI resources intentionally contain their respective languages.

Before submitting changes, run the JVM tests, debug build, and lint. Compile the Android tests; run privileged tests only on an isolated device. Describe what changed, why, and what was actually tested. Never include signing keys, passwords, local SDK paths, private logs, proprietary game bundles, or someone else's mod archives.

Contributions to covered original code and documentation are offered under the GNU GPL version 3 (GPL-3.0-only). Do not submit code or assets whose existing license conflicts with those terms. Preserve third-party notices and update the dependency inventory when changing dependencies. Artwork has separate rights; see CREDITS.md.
