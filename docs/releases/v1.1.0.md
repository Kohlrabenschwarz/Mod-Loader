# Mod Loader 1.1.0

Mod Loader 1.1.0 adds direct ZIP link imports, verified mod updates, Dev Mode publishing files, and approved replacement of matching imports.

## New features

- Tap **+** to open two round options: **Add from file** and **Add from link**. Public HTTPS ZIP links use the same package checks as the Android document picker and show download progress.
- Imports with the same name or stable mod ID show a conflict dialog. Cancel keeps existing mods unchanged; multiple matches let you select the card to overwrite. A different package restores the old active mod, keeps the card identity, retains the previous stored archive/backups, and stays inactive.
- Expand **Tap for details** to manually check a mod update. A root `update.json` points to an HTTPS `latest.json` manifest with version, exact ZIP size, and SHA-256. Downloads are verified before replacement, and interrupted directory exchanges recover on reconnect.
- Enable **Dev Mode** in Settings and save a publication root URL. Each stored mod gets `.dev/latest.json`, size/SHA-256 text files, a per-file checksum summary, and metadata templates. Each mod ID has a separate publishing directory. Missing or mismatched metadata produces a draft; the ZIP itself is never modified by sidecar generation.
- Search mods by name, creator, description, version, folder, or affected file. Search ignores case/accents and handles Turkish I variants; hidden active mods remain part of conflict checks.
- Remove the fixed 20-mod library and indirect 100-directory limits. Large library responses stream through a file descriptor to avoid Binder size failures.

## Reliability improvements

- Reconnect when Shizuku starts late, distinguish denied permission and unsupported backends, and provide a retry action.
- Keep healthy mods visible when an archive or record is damaged. Repair cached copies from verified stored archives; block privileged changes when unknown records could hide conflicts.
- Show the paths and hashes behind integrity warnings, retain new warnings after previously dismissed changes, and explain recovery/deletion effects.
- Show processing phases, transferred bytes, additional storage estimates, and conflicting mod names/files.
- Support 512 MiB payload files, 1 GiB ZIPs, and 2 GiB expanded payloads while retaining path, CRC, UnityFS header, and archive checks.
- Include all new controls in English, Turkish, German, Hindi, Russian, and Simplified Chinese.

## Installation

- Android 11/API 30 or newer, primary Android user.
- Shizuku through ADB/wireless debugging; root/Sui remains unsupported.
- Shadow Fight 4: Arena installed with game data downloaded.
- Production application ID: `dev.kohlrabenschwarz.ml`.
- Version name: `1.1.0`; version code: `17`.
- Signing certificate SHA-256: `c458512cf92fc4fd9e10c71af75ada3d997894d55e5d88a9845810e3cd434055`, matching release 1.0.0.

The APK is intended to update the existing production installation in place. Debug test installations use a separate package ID and signing identity.

ZIP hashes verify that a download matches its manifest; they do not authenticate a publisher or certify a mod as safe/compatible. Mod Loader is independent of Nekki/Banzai Games. Read the [User Agreement and Risk Notice](https://github.com/Kohlrabenschwarz/Mod-Loader/blob/main/TERMS.md) before using mods.
