# Mod Loader 1.0.0

Mod Loader 1.0.0 is the first production-ready release of the project. It brings the complete import, library, backup, recovery, integrity, localization, and update experience together in one signed Android application.

## Highlights

- Import mod ZIPs from Android’s document picker and keep them in a visual library.
- Read `info.json` metadata and show each mod’s icon, creator, description, version, and affected files.
- Support extensionless bundle names while requiring every payload to begin with the `UnityFS` header.
- Archive imported mods under the game’s reserved `Bundles/mods/` directory.
- Activate and deactivate mods with verified original-file backups.
- Resume interrupted operations using transaction journals.
- Detect game updates or outside changes with original and modified SHA-256 records.
- Recover base files, delete stored mods, or hide a warning without disabling integrity checks.
- Prevent overlapping active mods from managing the same destination.
- Show Shizuku status with three automatic connection attempts.
- Restart and launch Shadow Fight Arena from the Play button.
- Remember mod state, language, theme, and accent preferences.
- Provide English, Turkish, German, Hindi, Russian, and Simplified Chinese interfaces.
- Present the complete user agreement before privileged access begins, with an on-screen language selector.
- Check stable GitHub releases and hand downloads to the user’s browser.

## Safety work

The importer rejects path traversal, absolute paths, symbolic links, special files, hidden or reserved targets, Unicode display controls, ambiguous normalization, case collisions, encrypted entries, ZIP64 archives, compression bombs, oversized content, mismatched manifests, and non-`UnityFS` payloads. Privileged operations are restricted to the fixed Shadow Fight Arena package and Bundles tree.

These checks protect Mod Loader’s own file boundary. They do not prove that a third-party bundle is safe for Unity to parse, compatible with the current game, lawful to distribute, or free from harmful behavior.

## Requirements

- Android 11/API 30 or newer
- Shizuku running through ADB or wireless debugging as shell UID 2000
- Shadow Fight 4: Arena installed with its game data downloaded

Root/Sui mode and secondary Android users are not supported by this release.
