# Mod Loader 1.1.1

Search the mod library by name, creator, description, version, folder, or affected file. Searches support multiple words, ignore case and accents, and treat Turkish I/İ/ı consistently. The query survives screen recreation; clearing it restores the full list. Conflict checks include active mods hidden by the search.

The fixed 20-mod library limit and the engine's indirect 100-directory limit are removed. Large library responses now stream through a file descriptor to avoid Binder message-size failures. Existing archive protections remain, including 512 MiB per payload file, 1 GiB per ZIP, and 2 GiB expanded payloads.

Version code is 16. This update includes the connection, integrity, recovery, and progress improvements described in [1.1.0](v1.1.0.md).
